O que é cada coisa

Antes de começar, entenda o papel de cada peça. Pense numa aula: alguém explica, existe um material para praticar e você tem um caderno.

📘 O livro (PDF)
Explica o assunto e mostra as consultas que você vai digitar.
É o professor.
🗄️ Arquivos .db
Os bancos de dados, com as tabelas usadas no livro. Ficam na pasta do curso.
São como planilhas do Excel com os dados.
✍️ SQL
A linguagem em que você escreve perguntas para o banco, por exemplo “quais clientes moram no Texas?”.
São como as fórmulas do Excel.
💻 VS Code + SQLTools
Onde você escreve e roda suas consultas. Tudo fica salvo nos arquivos capXX.sql.
É o seu caderno.
🔍 DBeaver
Onde você olha as tabelas, as colunas e os dados com o mouse, e vê diagramas.
É o “explorador de arquivos” do banco.
🧩 SQLiteStudio
O programa que o livro usa. Você não precisa dele: o VS Code e o DBeaver fazem o mesmo.
Veja a página de “tradução”.

Parte 1 — Primeira vez (uns 15 minutos, só uma vez)

1.1

Abrir a pasta do curso no VS Code

  1. Abra o VS Code.
  2. Clique no menu File → Open Folder… (em português: Arquivo → Abrir Pasta…).
  3. Escolha a pasta C:\estudos\oreilly_getting_started_with_sql e clique em Selecionar pasta.
  4. Se aparecer a pergunta “Do you trust the authors of the files in this folder?”, clique em Yes, I trust the authors. no painel da esquerda (ícone de folhas, Explorer), os arquivos .db e a pasta estudos.
⚠ Importante: confira o canto inferior esquerdo Se aparecer escrito Restricted Mode no rodapé do VS Code, a pasta ainda não é confiável e o SQLTools fica desligado (o ícone dele não aparece). Clique em Restricted Mode → Trust e, se o VS Code pedir, recarregue a janela.
1.2

Conectar o VS Code a um banco (SQLTools)

  1. Na barra vertical de ícones da esquerda, clique no ícone de cilindro (desenho de banco de dados), chamado SQLTools.
    • Não achou? Aperte Ctrl+Shift+P, digite Reload Window e aperte Enter.
  2. Na seção CONNECTIONS aparecem 4 conexões: rexon_metals, weather_stations, surgetech_conference e extra_practice (Chinook).
  3. Passe o mouse sobre rexon_metals e clique no ícone de tomada (Connect) que aparece à direita.
  4. Só na primeira vez: no canto inferior direito aparece um aviso pedindo para instalar o sqlite3. Clique em Install now, espere de 1 a 2 minutos e clique na tomada de novo. um ponto verde ao lado do nome. Expandindo a seta, aparecem Tables → CUSTOMER, PRODUCT, CUSTOMER_ORDER.
1.3

Rodar a primeira consulta no VS Code

  1. Volte ao Explorer (ícone de folhas) e abra estudos → cap04_select.sql.
  2. Você verá a linha SELECT * FROM CUSTOMER;
  3. Logo acima dessa linha há um texto pequeno e clicável: Run on active connection. Clique nele.
    • Outra forma: selecione a linha com o mouse e aperte Ctrl+E duas vezes.
    uma aba à direita com uma tabela de 5 clientes. Você rodou SQL! 🎉
  4. Na barra inferior do VS Code aparece qual conexão está ativa (ex.: rexon_metals).
Lembre sempreA consulta roda no banco que está conectado. Ao trocar de capítulo, conecte no banco daquele capítulo antes de rodar.
1.4

Abrir o mesmo banco no DBeaver

  1. Abra o DBeaver pelo menu Iniciar.
  2. Se ele perguntar sobre “Create sample database”, clique em No. Outras janelas de boas-vindas podem ser fechadas.
  3. No painel esquerdo Database Navigator, abra a pasta Livro SQL. as mesmas 4 conexões do VS Code.
  4. Dê duplo clique em rexon_metals.
  5. Só na primeira vez: abre a janela “Download driver files”. Clique em Download e espere.
  6. Expanda rexon_metals → Tables → CUSTOMER e dê duplo clique em CUSTOMER. Abre uma janela com abas:
    AbaO que mostraNome no livro
    PropertiesAs colunas e o tipo de cada uma (INTEGER, TEXT…)Structure
    DataOs dados da tabela, linha por linhaData
    ER DiagramO desenho das tabelas e de como se ligam— (ajuda nos cap. 8 e 9)
  7. Para escrever SQL no DBeaver: clique com o botão direito em rexon_metals → SQL Editor → Open SQL script (atalho Ctrl+]). Escreva SELECT * FROM CUSTOMER; e aperte Ctrl+Enter. os mesmos 5 clientes, no painel de baixo.
✔ Pronto para começar? Confira:
  • O VS Code abre a pasta do curso sem Restricted Mode.
  • O SQLTools conecta no rexon_metals (ponto verde).
  • SELECT * FROM CUSTOMER; mostrou 5 clientes.
  • O DBeaver abre a pasta Livro SQL e mostra a tabela CUSTOMER.

Parte 2 — Rotina de cada sessão (60 minutos)

5 min
Preparar. Abra o PDF na página do capítulo (tabela abaixo). No VS Code, abra o arquivo capXX do dia e conecte no banco do capítulo.
15 min
Ler um pedaço do capítulo, por exemplo uma seção como “Expressões em instruções SELECT”.
25 min
Digitar e testar. Digite cada consulta do livro no seu arquivo (digite, não copie e cole). Rode e compare com a figura do livro. Depois mude algo (outra coluna, outro número) e veja o que acontece.
10 min
Criar. Escreva 1 ou 2 consultas suas sobre o mesmo assunto, por exemplo “quais produtos custam mais de 10?”.
5 min
Anotar. Escreva no fim do arquivo, em comentário (-- ...), o que aprendeu e suas dúvidas. Salve com Ctrl+S.
Ritmo sugeridoUm capítulo a cada 2 ou 3 sessões. O livro inteiro sai em cerca de 4 semanas.
Antes de rodar, confira o bancoCada capítulo usa um banco diferente. Veja na próxima página em qual banco conectar.

Exemplo completo: primeira aula do Capítulo 4

Assim fica uma sessão real. Use como modelo para os outros capítulos.

  1. Preparar: PDF na página 30. No VS Code, abra cap04_select.sql com o SQLTools conectado em rexon_metals.
  2. O livro pede a consulta abaixo, que já está no arquivo. Clique em Run on active connection. 
    SELECT * FROM CUSTOMER;
    5 clientes, com todas as colunas.
  3. Página 33: o livro mostra só duas colunas. Numa linha nova, digite e rode: 
    SELECT CUSTOMER_ID, NAME FROM CUSTOMER;
    agora só 2 colunas.
  4. Página 34: digite e rode esta consulta com uma coluna calculada: 
    SELECT
  PRODUCT_ID,
  DESCRIPTION,
  PRICE,
  PRICE * 1.07 AS TAXED_PRICE
FROM PRODUCT;
    Depois troque 1.07 por 1.10 e rode de novo. O que mudou?
  5. Sua consulta: tente escrever sozinho “mostrar a descrição e o preço com 5% de desconto”.
  6. Anotar no fim do arquivo: 
    -- Aprendi: SELECT escolhe colunas; * = todas; AS dá nome a uma coluna calculada.
-- Dúvida: ...
Regra de ouro no arquivo .sql Termine cada consulta com ; e deixe uma linha em branco entre uma consulta e outra. Assim o botão Run on active connection aparece em cima de cada uma e você roda uma por vez.

Quando algo der errado

ProblemaSolução
Não aparece o ícone do SQLTools (cilindro)Veja o canto inferior esquerdo. Se estiver escrito Restricted Mode, clique nele → Trust. Se não estiver: Ctrl+Shift+P → Reload Window.
no such table: CUSTOMERVocê está conectado no banco errado. Veja a barra inferior e conecte no banco do capítulo.
Não aparece “Run on active connection”Nenhuma conexão está ativa. Vá ao SQLTools e clique na tomada do banco.
Erro de sintaxe (syntax error near…)Confira as vírgulas entre as colunas, o ; no final e as aspas simples nos textos: 'Texto'.
Estraguei o banco nos capítulos 9 e 10Desconecte no SQLTools e no DBeaver. No terminal do VS Code (Ctrl+'), rode git restore surgetech_conference.db.
A chave externa não bloqueia nada (cap. 9 e 10)Rode antes, na mesma conexão: PRAGMA foreign_keys = ON;
5/2 deu 2No SQLite, inteiro dividido por inteiro dá inteiro. Use 5/2.0.
O DBeaver diz que o arquivo está bloqueadoFeche a conexão no VS Code (ou o contrário) antes de alterar dados.
Dica final Errar faz parte. Quando aparecer um erro, leia a mensagem com calma: quase sempre ela diz a linha e a palavra onde está o problema. Se travar, anote a dúvida no arquivo .sql e siga em frente.
